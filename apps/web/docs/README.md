## Tech Stack

- **Next.js 15** with App Router
- **React 19**
- **TypeScript**
- **Mantine UI** component library
- **TanStack Query** for data fetching
- **Zustand** for state management
- **React Hook Form** for forms (with Mantine integration)
- **NextAuth** for authentication
