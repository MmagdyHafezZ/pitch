# <Analytics>
## Overview
This microservice is responsible for <Collect, aggregate, and serve KPIs for Organizations, Teams, and Users: user counts, session metrics, scores, AI-usage (tokens&calls), leaderboards, and model-token expiry monitoring.>.  


## Features
# Managers features:
- Org metrics: <total users, active users, total sessions (time-range filter)>
- Team metrics: <users per team, team sessions, active users (time-range)>
- User/Team detail: <profile + last activity, sessions, avg score, AI usage, trends>
- Leaderboards:<top users score per sessions >
- Token expiry:<list of model api keys with expiry-times, alerts at Times days >
- Exports:<for audits; scheduled email summaries >

# user features:

- My sessions:<count, duration, recency (time-range) >
- My scores:<per session + rolling averages>
- Leaderboards:<view team standings and personal rank>
